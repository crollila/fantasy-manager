# Fantasy Manager 0.3.0

Download **Fantasy-Manager-Setup-0.3.0.exe** below and run it on Windows 10/11 x64. It includes the app, Python runtime and analysis engine. The installer is unsigned.

- Simpler team cards and one **Find my best lineup** action.
- Built-in ESPN sign-in window for importing your teams without copying cookies or IDs.
- Injury-aware recommendations, projected points, ranges and boom/bust estimates.
- Saved-roster analysis when offline; draft and research features under Advanced tools.
- Per-user installation, desktop shortcut and persistent local data.

Private ESPN leagues require you to sign in. ESPN may restrict embedded-browser login; the Chrome extension with the source/browser version remains available as a fallback. Empty or undrafted rosters cannot produce lineup advice. Recommendations never submit lineup changes to ESPN.

Validated with 42 Python tests, eight JavaScript tests, frozen-engine integration, and packaged/installed desktop UI tests. Source and downloads contain no user leagues, passwords or account sessions.
