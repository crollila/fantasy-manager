# Fantasy Manager 0.7.2

The first update delivered automatically.

## New: update button

The app now checks for a new version as soon as it opens (and every six hours while it stays
open). When one is out, a small glowing green **Update to x.y.z** button appears at the top,
next to the theme switch. The new version downloads in the background; press the button to
install it and restart. Pressed before the download finishes, it shows the progress and
installs as soon as it is done. If you never press it, the update installs the next time you
close the app.

This replaces the update banner from 0.7.1. Saved teams, the ESPN profile and prediction
history are kept.
